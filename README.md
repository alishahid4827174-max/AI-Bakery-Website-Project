# AI Bakery Website Project

## Overview
An AI-generated bakery website created using AI tools to design content, layout, and features.

## Features
- Responsive design
- Product listings (cakes, pastries, coffe,sandwiches)
- Clean UI with modern layout
- Menu with calories and flavors

## Tech / Tools
- ChatGPT (content & prompts)
- Lovable AI (site generation)
